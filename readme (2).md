# 🎲 Streamlit 로또 번호 생성기

Streamlit을 활용하여 버튼 클릭 한 번으로 중복 없는 6개의 로또 번호를 추첨하고, 실제 로또 공 색상 스타일로 시각화해 주는 웹 애플리케이션입니다.

## 📌 주요 기능

* **로또 번호 생성**: 1부터 45까지의 숫자 중 중복 없이 6개의 번호를 랜덤 추출 및 자동 정렬
* **최대 5개 세트 유지**: [로또번호 생성] 버튼을 누를 때마다 기록이 누적되며, 최대 5개 세트까지 화면에 표시
* **실제 로또 공 색상 적용**:
  * `1 ~ 10`: 노란색 🟡
  * `11 ~ 20`: 파란색 🔵
  * `21 ~ 30`: 빨간색 🔴
  * `31 ~ 40`: 보라색 🟣
  * `41 ~ 45`: 초록색 🟢

## 🛠️ 설치 및 실행 방법

### 1. 필수 패키지 설치

프로젝트 폴더 내에서 다음 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행

다음 명령어를 입력하여 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```

실행 후 웹 브라우저가 자동으로 열리며 로또 번호 생성기를 사용할 수 있습니다.
