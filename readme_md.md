# Streamlit 간단한 정수 계산기

Streamlit을 활용하여 두 정수와 연산자를 입력받아 결과를 출력하는 웹 기반 계산기 애플리케이션입니다.

---

## 📌 주요 기능

- **정수 입력**: 첫 번째 정수 및 두 번째 정수 입력 받기
- **연산자 선택**: 사칙연산 기호(`+`, `-`, `*`, `/`) 지원
- **예외 처리**:
  - 정수가 아닌 값 입력 시 오류 안내
  - `+`, `-`, `*`, `/` 외의 잘못된 연산자 입력 시 오류 안내
  - `0`으로 나누기 시도 시 오류 안내

---

## 🛠️ 설치 및 실행 방법

### 1. 필수 패키지 설치
프로젝트에 필요한 패키지를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
Streamlit 명령어를 통해 애플리케이션을 실행합니다.
```bash
streamlit run app.py
```
실행 후 브라우저가 열리며 계산기 화면이 나타납니다.
